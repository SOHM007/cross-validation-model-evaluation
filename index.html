About the Project

Cross-validation is a machine learning model evaluation technique used to estimate how well a model performs on unseen data.

In this project, different machine learning algorithms are compared using K-Fold Cross-Validation.

The models are evaluated using Accuracy, Precision, Recall and F1-Score.

How K-Fold Cross Validation Works

1

Split Dataset

The complete dataset is divided into K smaller groups called folds.

2

Train

K-1 folds are used to train the machine learning model.

3

Test

The remaining fold is used to test the model.

4

Average

The process is repeated K times and the scores are averaged.

Performance Metrics

Accuracy

Percentage of predictions that are correct.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision

Measures how many predicted positive cases are actually positive.

Precision = TP / (TP + FP)

Recall

Measures how many actual positive cases were correctly identified.

Recall = TP / (TP + FN)

F1-Score

Harmonic mean of precision and recall.

F1 = 2 × Precision × Recall / (Precision + Recall)
